# Приклад теки налаштувань

Структура, яку очікують механізми Aftertime--ENTERPRICE. Значення тут вигадані.
Справжня тека налаштувань організації лежить в окремому приватному репозиторії; її шлях
задається змінною `AFTERTIME_CONFIG_DIR` у `platform/.env`, наприклад:

```text
AFTERTIME_CONFIG_DIR=../../Aftertime-config
```

| Шлях | Що це |
|---|---|
| `e2e/bindings.json` | прив'язки процесів до E2E-кейсів: `title`, `phases`, `runner` (параметри для мосту запуску) |
| `models/` | процеси організації: `*.bpmn` і синхронні `*.svg` (див. `tools/models.py`) |
